# Змейка по сети (протокол v2) — Rust + TUI

Многопользовательская «Змейка»: игры в локальной сети (multicast `239.192.0.4:9193`) и на сервере курса
(`snakes.ippolitov.me:9193`) в одном списке. Терминальный интерфейс на ratatui.

## Запуск

    cargo run --release                       # обычный запуск
    cargo run --release -- --name Вася        # своё имя
    cargo run --release -- --no-animations    # без анимаций интерфейса
    cargo run --release -- --direction        # показывать направление головы змейки
    cargo run --release -- --no-server        # только локальная сеть
    cargo run --release -- --no-multicast --server 127.0.0.1:45101   # только «сервер» (проверка unicast-пути)
    cargo run --release -- --port 45101       # фиксированный порт игрового сокета
    cargo run --release -- --log trace.log    # журнал протокола (или SNAKE_LOG=trace.log)

## Устройство

    wire.rs      доменные сообщения, кодек prost/protobuf, конверсии и проверки
    rules.rs     правила: тор, ход, столкновения, очки, размещение, еда, конвертация змеек
    reliable.rs  ACK, повторы 100 мс, окно дедупликации 1024, Ping, тайм-аут связи 1000 мс
    catalog.rs   каталог игр (LAN + сервер), TTL 3 с
    node.rs      сетевое ядро без ввода-вывода: MASTER/DEPUTY/NORMAL, failover, выход
    node/joining.rs  подключение и восстановление: ACK, конфигурация и первый снимок
    net.rs       UDP-сокеты, multicast на всех интерфейсах, DNS-поток
    ui.rs        TUI: обработка ввода возвращает команды, которые выполняет главный цикл
    ui/animations.rs  эффекты tachyonfx: еда, волна по телу, появление/уход змеек, переходы экранов
    main.rs — цикл (потоков два: основной и DNS)

## Как читать код

1. `src/lib.rs` — карта модулей и общий поток данных.
2. `src/main.rs` — цикл ввода, сети, таймеров и отрисовки.
3. `src/node.rs` — автомат `Lobby → Joining → InGame`: `Phase` проверяет команды
   для текущей фазы, `Game` обрабатывает действия ведущего (`m_*`) и остальных
   участников (`p_*`); `src/node/joining.rs` отвечает за подключение.
4. `src/reliable.rs` и `src/wire.rs` — доставка сообщений и их представление.
5. `src/rules.rs` — расчёт одновременного хода независимо от сети.
6. `src/ui.rs` — состояние интерфейса; `Ui::handle_key` формирует команды, а главный
   цикл передаёт их узлу. Для существующих вызовов доступен также `Ui::on_key`.
7. `tests/sim.rs` — сценарии взаимодействия узлов без реальных сокетов.

Схема протокола находится в `protobuf/snakes.proto`. `build.rs` генерирует из неё
`src/snakes.v2.rs`; этот файл не редактируется вручную.

При отказе ведущего во время подключения клиент до трёх секунд ищет новый анонс
с тем же именем игры, в том числе опрашивая сервер курса. Найденный новый endpoint
начинает отдельную попытку с новым номером Join и сроком пять секунд. Как и в
задании, поиск по имени не отличает одноимённые игры разных серверов.

Документация модулей, типов и основных методов доступна через rustdoc:

    cargo doc --no-deps --open

Проверки и трассировка симулятора:

    cargo test
    SIM_TRACE=1 cargo test --test sim -- --nocapture
